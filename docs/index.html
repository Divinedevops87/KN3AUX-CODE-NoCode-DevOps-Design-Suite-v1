🌌 NoCode DevOps + Design Suite b.v1.0

DevOps + Design Suite in Dark Mode 🛠️🎨

📥 Installation & Usage

  1. Clone or download ZIP:
    git clone https://github.com/Divinedevops87/NoCodeDevOpsDesignSuite-bv1.0.git
  2. Install deps & build:
    npm ci && npm run build
  3. Load extension in your browser:
    • Go to chrome://extensions (or edge://extensions)
    • Toggle Developer Mode on
    • Click “Load unpacked” and select the dist folder
  4. Click the NoCode DevOps icon & let the dark-mode magic begin! ✨

📜 Features

  • 🌑 Full Dark-Mode UI with Emojis
  • 🖥️ One-click Termux Server Launch
  • ⚙️ Run DevOps & CI/CD Scripts
  • 🌈 Translucent Rainbow-Glow Logo
  • 📱 Mobile-Ready Popup & Responsive
  • 💾 Offline Enabled: All assets bundled
  • 🧩 TypeScript + CSS + HTML for type safety
  • 📢 Automatic page-injection banner

💻 Development

1. Install Node.js & npm (v16+).
2. Run npm ci to install dependencies.
3. Run npm run build to compile TS → JS.
4. Load the dist folder as an unpacked extension.

Tip: Use npm run watch for automatic rebuilds while editing TS. 🔄
